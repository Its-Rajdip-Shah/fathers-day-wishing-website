# Father's Day Tribute

**An interactive, responsive Father's Day tribute built as a personal web experience.**

The site combines animated visuals, handwritten-style storytelling, responsive layouts, and looping photo galleries into a single tribute page.

## What it includes

- responsive design for desktop and mobile
- interactive and animated visuals
- handwritten-style letter sections
- looping family photo galleries
- scroll-driven reveal and decorative transitions
- custom typography and visual theming

## Tech

`HTML` · `CSS` · `JavaScript`

## Run locally

No build step is required.


    python3 -m http.server 8000

Then open:

    http://localhost:8000

## Why

I built this as a personal project for Father's Day, with a focus on making the experience feel more like a small interactive story than a static greeting page.
